# 세특 수집기 · Speciality

과목별 QR코드로 학생의 학습·탐구 활동 응답을 수집하고, **1~7번 응답을 토대로 학교생활기록부 세부능력 및 특기사항(세특)을 자동으로 입력·편집**할 수 있는 교사용 웹앱입니다.

## 주요 기능

### 1. 과목 생성 및 QR코드 발급 (교사 관리 페이지 `/`)
- **다중 과목 관리**: 과목별로 독립된 수집 양식과 제출 목록을 관리합니다.
- **공동교육과정 지원**: 과목 설정에서 `공동교육과정` 옵션을 켜면 학생 접속 페이지에 **학교** 입력란이 자동으로 표시됩니다.
- **과목별 QR코드 생성**: 과목마다 학생 전용 접속 URL(`/?course=<과목ID>`) QR코드를 SVG/PNG로 즉시 생성하며, **교실 화면 크게 보기** 및 **QR 이미지 다운로드(PNG)**를 지원합니다.

### 2. 학생 전용 QR 접속 페이지 (`/?course=<과목ID>`)
- **세특 항목 완전 비노출**: 학생 접속 페이지에는 세부능력 특기사항 항목, 자동 생성 결과, 교사 관리 메뉴가 전혀 표시되지 않습니다.
- **수집 항목**:
  - 기본 정보: 학번, 이름, 학교(공동교육과정 과목인 경우)
  - 활동 내용(기본 7항목):
    1. 새로 알게 된 개념
    2. 과학적으로 더 정확히 알게 된 개념
    3. 인상 깊었던 활동 1
    4. 이유 1
    5. 인상 깊었던 활동 2
    6. 이유 2
    7. 내가 발전시킨 능력
- **입력 항목 자유 지정**: 교사가 웹앱의 `학생 입력 항목 설정` 탭에서 질문을 추가·수정·삭제·순서 변경하고 입력 유형(서술형/단답형/선택형)과 필수 여부를 지정할 수 있습니다.

### 3. 세부능력 특기사항 자동 입력 및 NEIS 지원
- 학생이 응답을 제출하는 즉시 1~7번(및 교사가 추가한 항목)을 토대로 **NEIS 개조식 문체(`~함.`, `~보임.`, `~이룸.`)**의 세특 초안이 서버에서 자동 생성되어 교사 화면에 입력됩니다.
- **3가지 문체 전환**: `탐구 중심형`, `성장 서사형`, `간결 요약형`
- **실시간 NEIS 바이트 계산기**: UTF-8 기준 1,500 Bytes 진행률 표시
- **선택적 Gemini AI 다듬기**: 교사 브라우저에 Gemini API 키를 입력하면 AI로 문장을 한 번 더 다듬을 수 있습니다.
- **엑셀(CSV) 내보내기**: UTF-8 BOM 포함 CSV로 다운로드하여 엑셀에서 한글 깨짐 없이 바로 활용할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

기본 포트 `3000`에서 실행됩니다 (`PORT=8080 npm start`로 변경 가능).
- 교사 관리 페이지: `http://localhost:3000/`
- 학생 접속 페이지: 과목별 QR코드 스캔 또는 `http://localhost:3000/?course=<과목ID>`
